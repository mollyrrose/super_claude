# DESIGN-PLAN.md template (P8 handoff contract for /qGoal)

The plan must be executable by /qGoal without reading the whole pipeline
history: every item names its target files (from AUDIT.md inventory), its
source proposal, and its acceptance check.

```markdown
# <Project> — Design Implementation Plan
Generated by /design-full on <state.updated>. Source of truth:
docs/design/BRANDBOOK.md (why) + docs/design/DESIGN.md (values) +
docs/design/proposals/ (what it should look like).

## Phase 1 — Foundations (tokens + global styles)
- [ ] Introduce design tokens: <target file(s), e.g. src/styles/tokens.css>
      From: DESIGN.md. Check: token names match DESIGN.md; wcag_check passes.
- [ ] Global typography + reset: <targets>
      From: DESIGN.md type section. Check: antipattern_lint AP08/AP12 clean.

## Phase 2 — Shell + navigation
- [ ] <component>: restyle per proposals/web/shell/variant-<winner>.html
      Targets: <files>. Check: visual parity with proposal at 1024px + 375px.
- [ ] Mobile nav: implement <winning nav approach> per proposals/mobile/.

## Phase 3 — Screen families
- [ ] <family>: <targets> per proposals/web/<family>/variant-<winner>.html
      Check: antipattern_lint clean; breakpoints 375/768/1024/1440 verified.

## Phase 4 — Customization layer
- [ ] design-config.json -> ship at <target path>
- [ ] Design tab: integrate proposals/design-tab/ per its WIRING.md
      Targets: <settings page files>. Check: toggles switch data-attrs; the
      reduced-motion media query force-disables flagged effects.
- [ ] Avatar assets: copy chosen set from proposals/avatars/<style>/ to
      <assets path>; wire picker per design-config.json.

## Phase 5 — Optional effects + polish
- [ ] <effect>: implement/link per design-config registry entry, including
      fallback and reduced-motion behavior.
- [ ] AJ60 polish sweep: favicons, selection colors, focus rings.

## Phase 6 — Roadmap-facing prep (planned features from AUDIT.md)
- [ ] <planned surface>: apply family <X> pattern when built; tokens already
      cover it. (One line per planned TODO/roadmap feature.)

## Acceptance (overall)
- antipattern_lint.py clean (or waivers listed) across changed surfaces.
- wcag_check.py: no AA failures on shipped pairs.
- Visual parity: winner proposals vs implemented screens at 2 breakpoints.
- No regression on <existing critical flows named in AUDIT.md>.
```

Sizing: mark each item S/M/L. Order is dependency order; qGoal executes
phase by phase. Items must reference ONLY files that exist in the audit
inventory or are explicitly new.
