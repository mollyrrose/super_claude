# Summary

browser-harness is a self-healing framework connecting LLMs to a real
browser via Chrome DevTools Protocol; the agent writes missing helper
functions itself as it goes. MIT license, ~538 commits, 253 PRs / 21 open
issues.

Alive and legitimate: active PR/issue volume indicates a real community,
