# Summary

claude-obsidian is a local-first, MIT-licensed integration between Obsidian
and Claude Code: it captures sources, builds connected notes, retrieves
grounded answers, and keeps the vault as plain Markdown (no lock-in) —
positioned as a "second brain" alternative to proprietary AI note tools.
Surfaced via GitHub trending with a strong trajectory (631 stars/day on
first appearance, 2,668 stars/week in the weekly view).

# Repo / source check

Alive and legitimate: tagged releases (latest v2.1.1), MIT license, ~254
commits, plausible commit history. Single-maintainer project, so normal due
diligence applies before any deep integration, but nothing here contradicts
the marketing.

# Why this is in the radar

Same "plain Markdown as the durable substrate, agent builds the connections"
philosophy this project's own memory-file + knowledge-graph layer follows,
just aimed at Obsidian's PKM audience rather than a coding-agent memory
layer. Reference-only: worth a look for UX ideas (how it surfaces connected
notes) rather than direct adoption, since this project's memory files are
not Obsidian-vault-shaped.
