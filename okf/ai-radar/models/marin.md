# Summary

Marin is an open research platform for training foundation models
end-to-end — data curation, tokenization, pretraining, posttraining, and
evaluation — backed by Stanford CRFM and Open Athena with Google TPU
Research Cloud access. Apache-2.0, ~10,183 commits, 488 open issues.

# Repo / source check

Alive and legitimate: institutional backing (Stanford CRFM) is a strong
credibility signal, active development, permissive license. Surfaced via
GitHub daily trending (255 stars/day), tied to a "Delphi Scaling Suite"
release (checkpoints and scaling laws) and an in-progress 500B+ parameter
MoE model generating research-community attention.

# Why this is in the radar

Not directly applicable to this project (no model-training workload here),
but a notable open-research counterweight to the closed frontier-lab model
releases already tracked in this topic (opus-5, sonnet-5, gpt-5-6, glm-5-3,
gemini-3-7-flash). Awareness entry only.
