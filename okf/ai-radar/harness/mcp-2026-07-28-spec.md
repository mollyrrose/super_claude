# Summary

The MCP spec dated 2026-07-28 moves the protocol core from
bidirectional/stateful to request/response, enabling serverless/edge MCP
servers. Adds a versioned extensions framework (MCP Apps, and a Tasks
extension where `tools/call` can return a task handle driven by
`tasks/get/update/cancel`), plus OAuth2/OIDC alignment for enterprise
identity.

# Why this is in the radar

Foundational protocol change underlying every MCP server this setup connects
to (GitHub MCP, others). Worth tracking for when/whether Claude Code's own
MCP client adopts the new extensions (Tasks in particular would matter for
long-running tool calls).
